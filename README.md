# LightPollutionMiku
The complete Arduino code I wrote for a hand-soldered LED Hatsune Miku Wig for an entry into MEFCC2025 Cosplay Competition, performance category. This uses the Adafruit NeoPixel for the LED strip animations! 

# Hardware 
I used an Arduino Nano hooked up to a few buttons and a power bank. One was to turn the entire thing 
on and off, the other to switch between different animation modes (off, static white, static teal, theatre chase, rainbow, standby, and the performance routine) 
The performance routine was timed to the background music.
