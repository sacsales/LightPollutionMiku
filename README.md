# LightPollutionMiku 🩵 
The complete Arduino code I wrote for a hand-soldered LED Hatsune Miku Wig for an entry into MEFCC2025 Cosplay Competition, performance category. This uses the Adafruit NeoPixel library for the LED strip animations! 


## Demo 
Miku in action! More footage on my cosplay instagram.

## Hardware 🎤
- An Arduino Nano hooked up to a few buttons, RGB LED strips (WS2812B) and a power bank. 
- One button was to turn the entire thing on and off, the other to switch between different animation modes (off, static white, static teal, theatre chase, rainbow, standby, and the performance routine) 
- The animations for the performance were timed to my background music. 
- The wiring actually was embedded under the pigtails and through a helmet wig, which connected via wires down the costume to the power bank in my pocket. The wig was about 3kg heavy...
